## How I Work

- **Local-first and self-hosted:** own the runtime, the data path, and the release chain.
- **Rust where it matters:** typed boundaries for CLIs, services, release gates, and long-lived automation.
- **Human-reviewed automation:** plans, dry-runs, approvals, and evidence before mutation.
- **Security as a default:** least privilege, network policy, secret rotation, signed artifacts, and redacted public surfaces.
- **Pragmatic compatibility:** modern Rust-first systems where possible, conventional PHP/shared-hosting paths where useful.
